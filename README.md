# ЛАБОРАТОРНА РОБОТА № 1
## Розгортання середовища автоматизації тестування. Структура проєкту та перший автоматизований тест

* **Дисципліна:** Автоматизація тестування
* **Спеціальність:** F2 «Інженерія програмного забезпечення», 4 курс
* **Виконавець:** Вако
* **Група:** Перша

---

## 📋 Опис проєкту
Цей проєкт створено в межах лабораторної роботи № 1 з метою розгортання та налаштування базового середовища для автоматизації тестування на базі **Node.js**, **TypeScript** та тест-раннера **Vitest**, а також налаштування засобів контролю якості коду (ESLint, Prettier).

---

## 📁 Структура проєкту

```text
qa-automation/
├── src/                    # Вихідний код програми (допоміжні функції, класи)
│   └── math.ts             # Приклад базової логіки для тестування
├── test/                   # Каталог для автоматизованих тестів
│   └── first.test.ts       # Перший автоматизований тест
├── .eslintrc.json          # Конфігурація лінтера ESLint
├── .prettierrc             # Конфігурація форматувальника коду Prettier
├── package.json            # Маніфест проєкту (залежності та скрипти)
├── tsconfig.json           # Налаштування компілятора TypeScript
├── vitest.config.ts        # Конфігурація фреймворку тестування Vitest
└── README.md               # Документація проєкту
```

## 🛠️ Передумови (Prerequisites)

Перед початком переконайся, що у тебе встановлено:
* **Node.js** (версія `>= 18.x`)
* **npm** (версія `>= 9.x`)

Перевірити версії можна командами:
```bash
node -v
npm -v
```

---

## 🚀 Інструкція зі встановлення та запуску

### 1. Клонування репозиторію та перехід у папку
```bash
git clone <URL_ВАШОГО_РЕПОЗИТОРІЮ>
cd qa-automation
```

### 2. Встановлення залежностей
Щоб уникнути конфліктів версій (якщо виникають проблеми з TypeScript 7+ та ESLint), рекомендується встановлювати залежності з прапорцем `--legacy-peer-deps`:

```bash
npm install --legacy-peer-deps
```

### 3. Доступні скрипти для запуску

* **Запуск тестів (одноразовий):**
  ```bash
  npm run test
  ```

* **Запуск тестів у режимі спостереження (Watch mode):**
  ```bash
  npm run test:watch
  ```

* **Перевірка покриття коду тестами (Coverage):**
  ```bash
  npm run coverage
  ```

* **Перевірка коду лінтером (ESLint):**
  ```bash
  npm run lint
  ```

* **Автоматичне виправлення помилок стилю (ESLint Fix):**
  ```bash
  npm run lint:fix
  ```

* **Форматування коду (Prettier):**
  ```bash
  npm run format
  ```
